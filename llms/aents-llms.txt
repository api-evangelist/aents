# AENTS (엔츠)

> AENTS is a Seoul, South Korea climate-technology company founded in 2021. Its product,
> AENTSCOPE (엔스코프), is an enterprise carbon-management and carbon-accounting SaaS platform
> for greenhouse-gas inventory, Scope 1/2/3 emissions calculation, third-party verification and
> regulatory disclosure reporting (KSSB, IFRS S2, CSRD, GRI, ISSB, CDP), plus product carbon
> footprint, CBAM, climate physical-risk analysis and Scope 3 supply-chain data collection.
> AENTS also runs an ESG consulting practice.

## Important: AENTS publishes no public API

AENTS is an API **consumer**, not an API provider. As of 2026-09-10 there is no public API,
developer portal, API reference, OpenAPI/AsyncAPI/GraphQL contract, SDK, MCP server, agent card
or webhook surface published on any AENTS host. AENTSCOPE's marketed integrations run inward:
it connects to the Korea Electric Power Corporation (한국전력 / KEPCO) API, the Allbaro (올바로)
national waste-management API, and customer ERP systems (SAP, Douzone) to collect activity data
automatically. Access to AENTSCOPE itself is by tenant sign-in at https://www.aentscope.com
("회사 이메일로 로그인" — sign in with your company email); pricing is by custom quote only.
